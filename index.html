Cơ sở dữ liệu Firestore đang bị khóa!

Firebase từ chối truy cập vì bạn chưa mở quy tắc bảo mật (Rules).

Để ứng dụng có quyền Thêm/Sửa/Xóa thời khóa biểu, vui lòng làm theo 4 bước sau:

  1. Vào Firebase Console, mở dự án bau-cu-hoi-an-dong.
  2. Ở menu bên trái, chọn thẻ Firestore Database.
  3. Chuyển sang tab Rules (Quy tắc) ở phía trên cùng.
  4. Xóa hết nội dung cũ, Copy và Dán đoạn mã dưới đây vào, sau đó bấm nút Publish (Xuất bản):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Lưu ý quan trọng: Sau khi bấm Publish trên Firebase, có thể mất đến 1-2 phút để quy tắc mới có hiệu lực. Hãy kiên nhẫn đợi một chút trước khi bấm Tải lại trang.
