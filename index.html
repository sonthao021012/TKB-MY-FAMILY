Cơ sở dữ liệu đang bị khóa!

Firebase từ chối truy cập vì chưa mở quy tắc bảo mật (Rules).

Vui lòng làm theo 4 bước sau để cấp quyền Ghi dữ liệu:

  1. Vào Firebase Console, mở dự án bau-cu-hoi-an-dong.
  2. Ở menu bên trái, chọn Firestore Database.
  3. Chuyển sang tab Rules (Quy tắc) ở phía trên cùng.
  4. Xóa hết code cũ, Copy đoạn mã dưới dán vào, và bấm nút Publish:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
